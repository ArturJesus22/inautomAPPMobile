# inautomAPPMobile

## Descrição

A aplicação móvel inautomAPPMobile é uma solução desenvolvida para a Inautom com o objetivo principal de monitorizar robôs industriais em tempo real. Esta aplicação permite aos utilizadores acompanhar o desempenho, estado e métricas operacionais dos robôs através de uma interface intuitiva e responsiva.

## Funcionalidades Principais

- **Monitorização em Tempo Real**: Acompanhamento do estado operacional dos robôs
- **Painel de Controlo**: Visualização de métricas e indicadores de desempenho
- **Notificações**: Alertas sobre eventos críticos ou anomalias
- **Gestão de Robôs**: Adição, configuração e organização de múltiplos robôs
- **Relatórios**: Gerar relatórios personalizáveis sobre a atividade dos robôs
- **Histórico de Operações**: Registo e consulta do histórico de atividades

## Tecnologias Utilizadas

- **React Native**: Framework para desenvolvimento multiplataforma
- **Redux**: Gestão de estado da aplicação
- **Socket.IO**: Comunicação em tempo real
- **APIs RESTful**: Integração com sistemas backend
- **Styled Components**: Estilização de componentes
- **Jest**: Testes unitários e de integração

## Requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn
- React Native CLI
- Android Studio (para desenvolvimento Android)
- Xcode (para desenvolvimento iOS, apenas em macOS)
